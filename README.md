# AutoApp

대중교통 경로 검색과 실시간 도착정보를 제공하는 로컬 웹앱입니다. Windows와 Node.js 24에서 실행하며 추가 패키지 설치가 필요하지 않습니다.

## 실행

1. 저장소를 내려받고 프로젝트 폴더에서 터미널을 엽니다.
2. `.env.example`을 `.env`로 복사해 본인의 API 인증키를 입력합니다.
3. `npm start`를 실행합니다. PowerShell 실행 정책 오류가 있으면 `npm.cmd start`를 사용합니다.
4. 브라우저에서 `http://127.0.0.1:4317`로 접속합니다. 종료는 터미널에서 `Ctrl+C`입니다.

키 없이도 화면을 열 수 있지만 실제 검색에는 인증키와 서비스 승인이 필요합니다. 키 변경 후 서버를 재시작합니다. `.env`와 개인 설정은 Git에 포함하지 않습니다.

| 환경변수 | 용도 |
| --- | --- |
| KAKAO_REST_API_KEY | 주소·장소 검색 |
| ODSAY_API_KEY | 대중교통 경로 검색 |
| SEOUL_SUBWAY_API_KEY | 지하철 실시간 도착정보 |
| SEOUL_BUS_API_KEY | 서울 버스 정류소정보조회 |
| GYEONGGI_BUS_API_KEY | 경기도 버스도착정보 조회 v2 |

버스는 각각의 서비스 활용 승인이 필요합니다. ODsay 서버 IP 제한을 사용하는 경우 실행 환경의 외부 공인 IP를 등록해야 합니다.

선택 사항: `local-settings.example.json`을 `local-settings.json`으로 복사하고 이동 이름, 출발지 주소, 도착지 장소명을 지정하면 초기 입력값으로 사용합니다. 이 파일도 Git에서 제외됩니다.

## 구현 기능

- 주소·장소 검색, 출발지·도착지 맞바꾸기
- 브라우저 저장, 불러오기, 수정, 복사 저장, 삭제
- 예상 소요시간 → 환승 횟수 → 도보시간 순으로 정렬하고 첫 경로에 ‘최적’ 표시
- 버스·지하철 탑승 횟수, 도보 구간 합산 시간, 예상 요금 표시
- 경로 상세 및 서울·경기 버스와 지원 지하철 실시간 도착정보
- 수동 새로고침과 화면을 보는 동안 30초 자동 갱신

## 범위와 제한

저장은 브라우저 localStorage를 사용합니다. 로그인·DB·기기 간 동기화·위치 추적·하차 알림·설치형 iOS 앱은 아직 구현하지 않았습니다. 지하철은 수도권 1~9호선 범위에서 역명과 다음 역 방향을 매칭하며, 종착역·급행 정차 여부는 별도 확인이 필요합니다. ‘최적’ 정렬은 실시간 대기시간을 반영하지 않습니다.

실시간 결과는 조회 시점에 따라 달라집니다. 경로 조회 정보는 서버 메모리에 30분간 유지되므로 만료 또는 서버 재시작 시 다시 검색합니다. 이 서버는 해당 컴퓨터에서만 접속하도록 설정돼 있으며 온라인 배포본은 아닙니다.

앱 화면에는 출처·제공기관 생성 시각·내부 캐시 정책을 표시하지 않는 원칙을 유지합니다.

## 검증

```sh
node --test routes.test.mjs arrivals.test.mjs arrival-display.test.mjs storage.test.mjs
npm run check
```

실서비스 검증 도구 `verify-live.mjs`, `inspect-transit.mjs`, `diagnose-arrivals.mjs`는 실제 키와 인터넷 연결이 필요합니다. 앞의 두 도구는 `local-settings.json`의 출발지 주소와 한국금융연수원 시험 경로를 사용하며 `--reverse`로 반대 방향을 확인할 수 있습니다.
